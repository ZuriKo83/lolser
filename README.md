# LOL AIR 서버 이용 가이드

![LOL AIR 로고](assets/logo.png)

LOL AIR는 리그 오브 레전드 내전, 일반 게임 구인, 서버 공지, 신고 처리를 한곳에서 관리하기 위한 디스코드 서버입니다.

이 문서는 처음 들어온 이용자가 **공지 확인 → 역할 확인 → 구인 참여 → 내전 참여 → 신고 및 제재 기준 확인** 순서로 서버를 이용할 수 있도록 정리한 공식 안내입니다.

- [내전 규정](내전규정.md)
- [서버 경고 기준](서버경고.md)
- [무통보 차단 리스트](무통보차단리스트.md)

---

## STEP 1. 모든 채널 표시

서버를 정상적으로 이용하려면 디스코드에서 **모든 채널 표시** 기능을 활성화해야 합니다.

해당 기능이 꺼져 있으면 공지, 가이드, 구인, 내전 대기방 등 주요 채널이 보이지 않을 수 있습니다.

## STEP 2. 닉네임 및 역할 확인

LOL AIR에서는 내전 밸런스와 구인 확인을 위해 본인의 정보가 식별 가능해야 합니다.

디스코드 상단의 **네임 변경** 또는 **채널 및 역할** 메뉴를 통해 닉네임과 역할을 확인해 주세요.

<img width="2141" height="1341" alt="채널및역할" src="https://github.com/user-attachments/assets/c8451325-edfb-4dfb-84db-350845d32ed6" />

권장 형식은 아래와 같습니다.

```text
닉네임 / 롤닉네임#태그 / 티어 / 주포지션
예시: 홍길동 / LOLAIR#KR1 / D4 / MID
```

티어 또는 포지션을 허위로 작성하면 내전 밸런스에 영향을 줄 수 있으므로 경고 대상이 될 수 있습니다.

---

## STEP 3. 필수 채널 확인

서버 이용 전 아래 채널을 먼저 확인해야 합니다.

| 채널 | 용도 |
|---|---|
| 📢 공지 | 서버 운영 공지, 필수 안내, 변경사항 확인 |
| 📌 가이드 | 서버 이용 방법, 구인 방법, 내전 참여 방법 확인 |
| ✅ 투표 | 서버 운영, 규칙 변경, 내전 방식 관련 투표 |
| ⚠️ 경고 | 규칙 위반 및 경고 처리 안내 |
| ⛔ 블랙리스트 | 서버 또는 내전 이용 제한 대상 안내 |
| 신고 | 비매너, 분쟁, 규칙 위반 제보 |

규정을 확인하지 않았다는 이유로 제재가 면제되지는 않습니다.

---

## STEP 4. 대화 및 정보 채널

| 채널 | 용도 |
|---|---|
| 채팅방 | 일반 대화 |
| TTS | 음성 읽기 기능 사용 |
| 자랑방 | 게임 결과, 하이라이트, 티어 달성, 플레이 장면 공유 |
| 패치노트 | 리그 오브 레전드 패치 및 서버 관련 변경사항 확인 |

채널 목적과 맞지 않는 글을 반복적으로 작성하면 경고가 부여될 수 있습니다.

---

## STEP 5. 게임 구인 채널

| 채널 | 용도 |
|---|---|
| 구인방법 | 구인 작성 방식과 참여 방법 확인 |
| 게임방 생성기 | 일반 게임, 자유 랭크, 칼바람 등 게임방 생성 |

구인 시에는 게임 모드, 인원, 포지션, 시작 시간을 명확하게 작성해야 합니다.

```text
소환사의 협곡 자유랭크 5인 모집
현재 인원: 3/5
필요 포지션: JG, SUP
시작 예정: 인원 완료 즉시
```

---

## STEP 6. 내전 구인 채널

| 채널 | 용도 |
|---|---|
| 구인 | 내전 참가자 모집 |
| 버튼 | 내전 참가 버튼 또는 봇 기능 사용 |
| 시작로그 | 내전 시작 기록 확인 |
| 종료로그 | 내전 종료 기록 확인 |

내전 모집 메시지에서 참가 버튼을 누르면 팀 또는 참가 정보가 기록됩니다.

장난으로 참가하거나, 참가 후 무단 이탈하면 내전 진행 방해로 처리될 수 있습니다.

---

## STEP 7. 내전 대기 음성채널

내전 진행 시 참가자는 배정된 조에 맞는 음성채널로 이동해야 합니다.

| 음성채널 | 용도 |
|---|---|
| 1조내전대기 | 1조 내전 대기 |
| 2조내전대기 | 2조 내전 대기 |
| 3조내전대기 | 3조 내전 대기 |
| 4조내전대기 | 4조 내전 대기 |
| 5조내전대기 | 5조 내전 대기 |
| 6조내전대기 | 6조 내전 대기 |
| 7조내전대기 | 7조 내전 대기 |
| 8조내전대기 | 8조 내전 대기 |
| 9조내전대기 | 9조 내전 대기 |
| 10조내전대기 | 10조 내전 대기 |

잘못된 대기방에 들어가면 팀 배정과 진행에 혼선이 생길 수 있으므로 반드시 본인이 배정된 조의 대기방을 이용해야 합니다.

---

## STEP 8. 신고 및 문의

문제가 발생하면 **신고** 채널을 사용하거나 운영진에게 문의해야 합니다.

신고 시에는 아래 자료를 함께 제출하는 것이 좋습니다.

- 문제 발생 시간
- 관련 이용자
- 채팅 캡처
- 음성 또는 게임 상황 설명
- 게임 결과 화면
- 시작로그 또는 종료로그
- 기타 증거 자료

허위 신고, 보복성 신고, 증거 조작은 경고 또는 차단 대상입니다.

---

## 기본 이용 규칙

LOL AIR에서는 도배, 분쟁 유발, 과도한 훈수, 특정 이용자 비난, 부적절한 닉네임 또는 프로필 사용, 운영진 안내 불응, 봇 기능 악용, 내전 모집 방해, 허위 신고, 위험 링크 공유, 부정 프로그램 또는 계정 거래 관련 행위를 금지합니다.

위반 시 서버 경고, 타임아웃, 추방, 차단 등의 조치가 적용될 수 있습니다.

---

## 경고 및 차단 기준

서버 경고는 내전, 채팅, 음성 채널, 신고 처리 등 서버 활동 전반에 적용됩니다.

경고는 누적제로 운영되며, **경고 5회 누적 시 서버 추방** 처리됩니다.

경고 기준은 [서버 경고 기준](서버경고.md), 즉시 차단 기준은 [무통보 차단 리스트](무통보차단리스트.md)를 따릅니다.

---

## 운영진 재량 조치

규정에 명확히 적혀 있지 않은 상황이라도 서버 분위기, 이용자 안전, 내전 진행, 운영 질서에 피해를 주는 행위가 발생하면 운영진은 재량에 따라 조치할 수 있습니다.

운영진은 신고 내용, 대화 기록, 반복성, 고의성, 피해 정도를 종합하여 최종 제재 수위를 결정합니다.
