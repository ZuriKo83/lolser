# LOL AIR 서버 이용 가이드

LOL AIR는 리그오브레전드 내전과 커뮤니티 활동을 위한 디스코드 서버입니다. 서버 이용자는 아래 가이드와 서버 규칙을 확인한 것으로 간주됩니다.

---

## STEP 1. 모든 채널 표시

서버를 정상적으로 이용하려면 디스코드에서 **모든 채널 표시** 기능을 활성화해야 합니다.

해당 기능이 꺼져 있으면 공지, 가이드, 구인, 내전 대기방 등 주요 채널이 보이지 않을 수 있습니다.

## STEP 2. 닉네임 규정 확인

LOL AIR에서는 내전 밸런스, 구인 확인, 티어 역할 관리를 위해 닉네임을 정해진 양식에 맞게 작성해야 합니다.

### 닉네임 작성 양식

```text
닉네임 / 롤닉네임#태그 / 티어
예시: 나미 / 나미#KR1 / D4
```

### 닉네임 규정 위반 유형

| 유형 | 설명 |
|---|---|
| 위장티어 | 실제 티어를 고의로 숨기거나 낮춰 작성한 경우. 확인 시 무조건 블랙 처리됩니다. |
| 티어 오기재 | 실수로 실제 티어와 다르게 작성한 경우 |
| 검색 불가 | 작성한 롤 닉네임 또는 태그로 계정 확인이 불가능한 경우 |
| 양식 불일치 | 서버 닉네임 양식과 맞지 않는 경우 |
| 불건전한 닉네임 | 욕설, 비하, 혐오, 선정적 표현 등 타인에게 불쾌감을 줄 수 있는 경우 |
| 티어 변동 미반영 | 티어 변경 후 역할 또는 닉네임을 수정하지 않은 경우 |

본인의 티어는 `https://www.fow.lol/` 사이트에서 확인할 수 있습니다.

닉네임 규정 위반 역할이 부여된 경우 아래 순서대로 처리합니다.

1. 닉네임 규정을 다시 확인합니다.
2. 디스코드 닉네임을 양식에 맞게 수정합니다.
3. `채널 및 역할`에서 본인에게 맞는 역할을 선택합니다.
4. `📌╰채널해금` 채널에 닉네임 증명이 가능한 자료를 제출합니다.

관리자 개인 DM 문의는 받지 않는 것을 원칙으로 하며, 지정된 채널을 통해 처리합니다.

## STEP 3. 역할 확인

디스코드 상단의 **네임 변경** 또는 **채널 및 역할** 메뉴를 통해 본인의 역할을 확인해야 합니다.

역할은 구인, 내전, 이벤트, 티어 구분에 사용됩니다.

<img width="2141" height="1341" alt="채널및역할" src="https://github.com/user-attachments/assets/c8451325-edfb-4dfb-84db-350845d32ed6" />

역할이 잘못 부여되었거나 티어가 변경된 경우 직접 수정 후 `📌╰채널해금`에 다시 제출합니다.

## STEP 4. 필수 채널 확인

서버 이용 전 아래 채널을 먼저 확인해야 합니다.

| 채널 | 용도 |
|---|---|
| 📢 공지 | 서버 운영 공지, 필수 안내, 변경사항 확인 |
| 📌 가이드 | 서버 이용 방법, 구인 방법, 내전 참여 방법 확인 |
| ✅ 투표 | 서버 운영, 규칙 변경, 내전 방식 관련 투표 |
| ⚠️ 경고 | 규칙 위반 및 경고 처리 안내 |
| ⛔ 블랙리스트 | 서버 또는 내전 이용 제한 대상 안내 |
| 신고 | 비매너, 분쟁, 규칙 위반 제보 |

## STEP 5. 대화 및 정보 채널

| 채널 | 용도 |
|---|---|
| 채팅방 | 일반 대화 |
| TTS | 음성 읽기 기능 사용 |
| 자랑방 | 게임 결과, 하이라이트, 티어 달성, 플레이 장면 공유 |
| 패치노트 | 리그 오브 레전드 패치 및 서버 관련 변경사항 확인 |

채널 목적과 맞지 않는 글을 반복적으로 작성하면 경고가 부여될 수 있습니다.

## STEP 6. 게임 구인 방법

게임 구인은 **게임 구인 > 구인방법** 채널의 양식에 맞춰 작성합니다.

구인 글에는 게임 유형, 티어, 인원 수, 음성방 링크, 마감 여부를 명확히 적어야 합니다.

### 구인 작성 기준

```text
@게임에 맞는 역할 멘션
@티어 역할 멘션
구인 인원 수 또는 방 링크
마감 시 이모지 또는 마감 표시
게임방 생성기 클릭 후 이동되는 음성방 링크 입력
```

### 역할 멘션 예시

| 구분 | 예시 |
|---|---|
| 게임 유형 | 솔랭, 자랭, 일반 게임, 칼바람, 롤토체스, 이벤트 게임, 격전, 타게임 |
| 티어 | 챌린저, 그마, 마스터 300+, 마스터 -300, 다이아, 에메랄드, 플레, 골드, 실버, 브론즈, 아이언 |
| 모집 정보 | 구인 인원 수, 방 링크, 마감 여부 |

구인 공고 시 `@게임 유형` `@티어` `인원 수` `음성방 링크`를 올려주세요.

음성방을 생성한 뒤에는 채널명을 **닉네임 / 게임명** 형식으로 수정하는 것을 권장합니다.

```text
예시: 나미 / 자유랭크
예시: 나미 / 칼바람
```

## STEP 7. 내전 구인 채널

내전은 **내전 구인** 카테고리에서 모집하고 기록합니다.

| 채널 | 용도 |
|---|---|
| 구인 | 내전 참가자 모집 |
| 버튼 | 내전 참가 버튼 또는 봇 기능 사용 |
| 시작로그 | 내전 시작 기록 확인 |
| 종료로그 | 내전 종료 기록 확인 |

내전 모집 메시지에서 참가 버튼을 누르면 참가 상태가 기록됩니다. 장난으로 참가하거나 참가 후 무단 이탈하면 내전 진행 방해로 처리될 수 있습니다.

---

## STEP 8. 내전 참가 버튼 사용법

**버튼** 채널에는 조별 내전 참가 메시지가 표시됩니다.

내전 시작 전에는 내전대기 음성 채널에서 대기해야 하며, 조 편성 이후 본인 조와 팀에 맞는 버튼을 눌러 이동합니다.

| 버튼 | 설명 |
|---|---|
| 조 참가 | 해당 조 대기 목록에 참가합니다. |
| 참가 취소 | 현재 조 참가를 취소합니다. |
| A팀 참가 | 해당 조의 A팀으로 참가합니다. |
| B팀 참가 | 해당 조의 B팀으로 참가합니다. |
| 게임 시작 | 정원 충족 후 시작 로그를 남깁니다. |
| A팀 승리 / B팀 승리 | 승리 로그를 남기고 다음 판 대기 상태로 전환합니다. |
| 내전 종료 | 해당 조의 내전을 종료합니다. |

참가 버튼을 누르기 전 본인이 들어갈 조와 팀을 반드시 확인해야 합니다. 임의로 팀을 이동하거나 지정되지 않은 음성방에 들어가는 행위는 제한될 수 있습니다.

---

## STEP 9. 내전 대기 음성채널

내전 진행 시 참가자는 배정된 조에 맞는 음성채널로 이동해야 합니다.

| 음성채널 | 용도 |
|---|---|
| 1조내전대기 | 1조 내전 대기 |
| 2조내전대기 | 2조 내전 대기 |
| 3조내전대기 | 3조 내전 대기 |
| 4조내전대기 | 4조 내전 대기 |
| 5조내전대기 | 5조 내전 대기 |
| 6조내전대기 | 6조 내전 대기 |
| 7조내전대기 | 7조 내전 대기 |
| 8조내전대기 | 8조 내전 대기 |
| 9조내전대기 | 9조 내전 대기 |
| 10조내전대기 | 10조 내전 대기 |

잘못된 대기방 이용은 팀 배정과 진행에 혼선을 줄 수 있으므로 반드시 본인이 배정된 조의 대기방을 이용해야 합니다.

## STEP 10. 신고 및 문의

문제가 발생하면 **신고** 채널을 사용하거나 운영진에게 문의해야 합니다.

신고 시에는 아래 자료를 함께 제출하는 것이 좋습니다.

- 문제 발생 시간
- 관련 이용자
- 채팅 캡처
- 음성 또는 게임 상황 설명
- 게임 결과 화면
- 시작로그 또는 종료로그
- 기타 증거 자료

허위 신고, 보복성 신고, 증거 조작은 경고 또는 차단 대상입니다.

## 내전 경고 기준

내전 경고는 내전 진행 방해, 참가 약속 불이행, 비매너, 게임 진행 방해 등 내전 운영과 직접 관련된 행위에 적용됩니다.

| 항목 | 조치 |
|---|---|
| 내전 참가를 눌러놓고 불참 | 내전경고 2회 |
| 시간 약속 10분 지각 | 내전경고 1회 |
| 불쾌감을 주는 이모티콘 연발 | 내전경고 1회 |
| 이유 없는 퍼즈 2분 | 내전경고 1회 |
| 상대방에게 폭언 및 욕설 | 내전경고 2회 |
| 비매너 행위 | 내전경고 2회 |
| 고의 트롤링 | 내전경고 3회 |
| 팀 내 사기 저하 또는 분위기 조성 | 내전경고 3회 |
| 포스트 채널에서 본인 글, 댓글, 대댓글 삭제 | 내전경고 1회 |

내전경고 5회 누적 시 1일 타임아웃이 적용될 수 있습니다.
내전경고 5회 누적 시 서버경고 1회로 치환될 수 있습니다.

## 내전블랙 기준

내전블랙은 내전 참여 제한 조치입니다. 운영진은 위반 정도에 따라 1일에서 7일까지 내전블랙을 부여할 수 있습니다.

| 항목 | 조치 |
|---|---|
| 내전 진행 방해 반복 | 내전블랙 1~7일 |
| 내전경고 누적 또는 중대한 비매너 | 내전블랙 1~7일 |
| 운영진 판단상 내전 진행에 지장을 주는 행위 | 내전블랙 1~7일 |

내전블랙이 적용되면 지정된 기간 동안 내전 관련 이용이 제한될 수 있습니다. 남은 기간은 서버 봇 명령어로 확인할 수 있습니다.

## 블랙 기준

아래 행위는 누적 경고와 관계없이 블랙 처리될 수 있습니다.

| 항목 | 조치 |
|---|---|
| 위장티어 | 무조건 블랙 |
| 유해 유인물 배포 | 서버 블랙 |
| 개인 뒷거래 | 서버 블랙 |
| 아이디 빌려주기 | 서버 블랙 |
| 남들이 불쾌할 만한 닉네임 사용 | 서버 블랙 |
| 부정 재가입 | 서버 블랙 |
| 운영진 또는 서버 의사결정 불수용 | 서버 블랙 |

블랙 처리자는 서버 또는 내전 이용이 제한될 수 있으며, 운영진 판단에 따라 차단 조치가 적용될 수 있습니다.

## 경고 및 차단 기준

서버 경고는 채팅, 음성, 신고 처리, 내전 외 활동 등 서버 활동 전반에 적용됩니다.

내전 경고는 내전 운영과 직접 관련된 행위에 적용되며, 위 기준표에 따라 처리됩니다.

| 기준 | 조치 |
|---|---|
| 서버경고 1회 이상 | 서버경고 역할이 부여될 수 있습니다. |
| 서버경고 5회 누적 | 서버 추방 또는 차단 처리될 수 있습니다. |
| 내전경고 5회 누적 | 1일 타임아웃이 적용될 수 있습니다. |
| 내전경고 5회 누적 | 서버경고 1회로 치환될 수 있습니다. |
| 내전블랙 적용 | 지정 기간 동안 내전 이용이 제한될 수 있습니다. |
| 블랙 기준 해당 행위 | 누적 경고와 관계없이 서버 또는 내전 이용 제한 |
| 심각한 위반 | 누적 경고와 관계없이 즉시 제한될 수 있습니다. |

경고 기준은 서버 경고 기준, 즉시 차단 기준은 블랙 기준을 따릅니다.

## 포스트 채널 삭제 규정

포스트 채널에서는 기록 보존과 분쟁 방지를 위해 작성자가 본인의 글, 댓글, 대댓글을 임의로 삭제하는 행위를 제한합니다.

| 행위 | 조치 |
|---|---|
| 본인 포스트 삭제 | 내전경고 1회 |
| 본인 댓글 삭제 | 내전경고 1회 |
| 본인 대댓글 삭제 | 내전경고 1회 |

관리자가 운영상 필요에 따라 삭제한 경우는 제외됩니다.

## 포인트 및 상점 이용 규칙

서버 포인트는 LOL AIR 서버 내부 콘텐츠 이용을 위한 전용 포인트입니다.

- 포인트는 현금, 상품권, 기프티콘, 계좌이체, 현물로 환급되지 않습니다.
- 포인트는 유저 간 판매, 구매, 양도, 대리 구매, 계정 거래에 사용할 수 없습니다.
- 포인트는 현금과 동일한 가치를 보장하지 않으며, 서버 운영 정책에 따라 지급량과 사용처가 변경될 수 있습니다.
- 랜덤박스 보상 포인트는 후원 포인트가 아닌 이벤트 보상 포인트로만 지급됩니다.
- 랜덤박스는 서버 내부 재미 요소이며, 현금 환급, 양도, 거래가 불가능합니다.

## 봇 명령어와 자동 처리 기준

서버 봇은 규칙 적용을 돕기 위한 보조 수단이며, 운영진의 최종 판단을 대체하지 않습니다.

| 명령어 또는 기능 | 용도 |
|---|---|
| `/내전블랙` | 운영진이 유저에게 1~7일 내전블랙을 부여합니다. |
| `/내전블랙해제` | 운영진이 유저의 내전블랙을 해제합니다. |
| `/내전블랙확인` | 유저가 내전블랙 남은 기간을 확인합니다. |
| `/내전블랙목록` | 운영진이 내전블랙 자동 해제 대기 목록을 확인합니다. |
| `/기간제역할목록` | 운영진이 기간제 역할 자동 해제 대기 목록을 확인합니다. |
| `/상점서버` | 서버경고 감면권, 내전블랙 제거권 등 서버 관련 상점을 표시합니다. |
| `/상점기본` | 퍼스트 클래스, 커스텀 역할, 포로 등 기본 상점을 표시합니다. |
| `/상점온에어` | ON AIR 관련 상점을 표시합니다. |
| `/랜덤박스` | 랜덤박스 상점을 표시합니다. |
| `/후원상점` | 서버 운영 지원 신청을 위한 문의 채널을 생성합니다. |
| `/백업` | 운영 데이터 백업을 수동 생성합니다. |

자동 역할 부여, 자동 해제, 포인트 차감, 로그 기록은 봇 설정과 디스코드 권한 상태에 따라 처리됩니다. 봇 권한 부족, 역할 순서 문제, 채널 삭제, 유저 탈퇴 등으로 자동 처리가 실패할 수 있으며, 이 경우 운영진이 수동으로 확인합니다.

## 운영진 재량 조치

규정에 명확히 적혀 있지 않은 상황이라도 서버 분위기, 이용자 안전, 내전 진행, 운영 질서에 피해를 주는 행위가 발생하면 운영진은 재량에 따라 조치할 수 있습니다.

운영진은 신고 내용, 대화 기록, 반복성, 고의성, 피해 정도를 종합하여 최종 제재 수위를 결정합니다.
