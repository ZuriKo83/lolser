# 나미봇 내전 서버 가이드

나미봇 내전 서버는 리그 오브 레전드 내전을 더 편하게 모집하고, 팀을 나누고, 규칙에 따라 관리하기 위한 디스코드 서버입니다.

이 문서는 서버 이용 방법, 내전 참여 방법, 경고 기준, 무통보 차단 기준을 안내합니다.

## 내전 참여 방법

내전은 나미봇이 생성한 내전 모집 메시지를 통해 참여합니다.

내전 모집 메시지에는 현재 참가 인원, A팀 인원, B팀 인원이 표시됩니다.

---

## 버튼 설명

| 버튼 | 설명 |
|---|---|
| A팀 참가 | A팀으로 내전에 참가합니다. |
| B팀 참가 | B팀으로 내전에 참가합니다. |
| 내전 종료 | 해당 내전 모집을 종료합니다. |

각 팀은 최대 5명까지 참가할 수 있습니다.

A팀 5명, B팀 5명으로 총 10명이 채워지면 내전 시작 로그가 자동으로 남습니다.

참가자는 본인이 참가한 팀과 포지션 정보를 반드시 확인해야 합니다.

잘못된 정보로 참가한 경우 즉시 운영진 또는 진행자에게 수정 요청을 해야 합니다.

---

## 참가 정보 작성 기준

내전에 참가할 때는 본인의 정보를 정확히 작성해야 합니다.

필수 정보는 아래와 같습니다.

- 디스코드 닉네임
- 롤 닉네임 또는 태그
- 시즌 정보
- 주 포지션
- 티어 정보

정보를 허위로 작성하거나, 팀 밸런스에 영향을 줄 정도로 부정확하게 작성하면 경고가 부여될 수 있습니다.

## 경고 시스템

서버의 경고는 내전, 채팅, 음성 채널, 신고 처리 등 서버 활동 전반에 적용됩니다.

경고는 누적제로 운영되며, **경고 5회 누적 시 서버 추방** 처리됩니다.

마지막으로 경고를 받은 날로부터 **3개월이 지난 뒤**, 반성문을 작성하면 운영진 검토 후 **경고 1회가 차감**될 수 있습니다.

단, 반성문 작성만으로 무조건 차감되는 것은 아니며, 운영진은 태도 변화와 재발 가능성을 검토하여 차감 여부를 결정합니다.

자세한 기준은 `서버경고.md`를 확인하세요.

## 신고 및 문의

서버 이용 중 문제가 발생한 경우 운영진에게 문의하거나 신고 채널을 이용해야 합니다.

신고 시에는 가능한 한 아래 자료를 함께 제출해야 합니다.

- 문제 발생 시간
- 관련 이용자
- 채팅 캡처
- 음성 또는 게임 상황 설명
- 게임 결과 화면
- 기타 증거 자료

허위 신고 또는 악의적인 신고는 경고 대상입니다.

## 운영진 재량 조치

규정에 명확히 적혀 있지 않은 상황이라도 서버 분위기, 이용자 안전, 운영 질서에 피해를 주는 행위가 발생한 경우 운영진은 재량에 따라 조치할 수 있습니다.

운영진은 신고 내용, 대화 기록, 반복성, 고의성, 피해 정도를 종합하여 최종 제재 수위를 결정합니다.
